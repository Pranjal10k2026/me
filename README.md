# Pranjal's Portfolio

A personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui.

## Run locally

Install Node.js and npm, then run:

```bash
npm ci
npm run dev
```

Open the URL printed in the terminal. Press Ctrl+C to stop the server.

## Check and build

```bash
npm run lint
npm run build
npm run preview
```

The production build is created in `dist/`.

## Deployment

The site is deployed to GitHub Pages by GitHub Actions when changes are pushed to the `main` branch.

Live site: https://pranjal10k2026.github.io/me/
